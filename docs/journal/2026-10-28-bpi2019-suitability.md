# BPI 2019 원본 구매 로그의 연구 적합성

10월 28일 BPI Challenge 2019 원본 XES 로그 전체를 검사했습니다. 판단은 조건부 적합입니다. 실제 구매 이벤트의 근거 검토에는 사용할 수 있지만 제조 BOM·인증서 영향 분석이나 실제 지급 적합성을 바로 평가하는 자료는 아닙니다. 새 모델 실험은 실행하지 않았고 기존 제조 연구 프로토콜도 변경하지 않았습니다.

## 원천과 검사 범위

[공식 챌린지 페이지](https://icpmconference.org/2019/icpm-2019/contests-challenges/bpi-challenge-2019/)가 연결한 압축 XES를 확보했습니다. 출처는 van Dongen, B.F., Dataset BPI Challenge 2019, 4TU.Centre for Research Data이며 [DOI](https://doi.org/10.4121/uuid:d06aff4b-79f0-45e6-8ec8-e19730c248f1)를 보존합니다. 압축 파일은 16,901,365바이트이고 해제한 XML은 728,558,522바이트입니다.

두 번의 전체 순회로 구조와 시각을 확인했습니다. 압축 파일과 해제한 데이터의 SHA-256, 압축 무결성, 활동·유형·연도별 집계의 합계를 대조했습니다. 원본 시각은 모두 고정된 UTC 형식으로 파싱됐습니다. 날짜 문법이 유효하다는 사실이 현실의 날짜가 맞다는 뜻은 아닙니다.

| 항목 | 관측값 |
|---|---:|
| 발주 문서 | 76,349개 |
| 발주 항목 | 251,734개 |
| 이벤트 | 1,595,923개 |
| 활동 유형 | 42개 |
| 입고 또는 송장 수신이 여러 번 기록된 항목 | 17,834개 |
| 이름에 Cancel이 포함된 활동이 있는 항목 | 8,357개 |
| 동일 시각의 이벤트가 있는 항목 | 19,365개 |

[공개 집계와 검사 조건](../experiments/records/20261028-bpi2019-suitability.json)에 출처·해시·카운터 정의를 남깁니다. 저장소 메타데이터 요청은 시간 초과로 실패했고 재배포 라이선스를 확인하지 못했습니다. 원본 로그와 행 단위 발췌본은 게시하지 않습니다.

## 직접 구성할 관계와 남는 불확실성

발주 문서와 항목 식별자는 전체 로그에서 일관되게 연결됐습니다. 이벤트는 해당 항목에 포함됩니다. 그러나 이벤트 속성은 User, org:resource, concept:name, Cumulative net worth (EUR), time:timestamp의 다섯 개뿐입니다. 개별 입고·송장 문서 ID는 이 이벤트 속성에 없습니다. 여러 입고와 송장을 일대일로 연결하려면 별도 근거가 필요합니다.

Consignment와 3-way match, invoice before GR는 Goods Receipt=true, GR-Based Inv. Verif.=false라는 같은 플래그 조합을 사용합니다. 두 플래그만으로 같은 규칙을 적용할 수 없습니다. 유형의 뜻과 예외를 함께 해석해야 합니다. 유형 예측을 평가한다면 정답에 해당하는 Item Category를 모델 입력에 그대로 제공하지 않도록 설계해야 합니다.

금액 필드의 누적 의미와 취소·변경 처리 방식은 아직 확정하지 않았습니다. 모든 이벤트 금액을 단순 합산해 정산 적합성을 판정하지 않습니다. 승인 관련 활동명이 일부 있지만 전체 승인 권한·이력을 복원할 근거가 충분하다는 뜻도 아닙니다.

## 시각과 누락의 처리

2017~2019년을 탐색용 구간으로 보았을 때 바깥에 있는 이벤트는 97개이고 이를 포함한 항목은 82개입니다. 1948년 시각도 10개 발견했습니다. 이 구간은 공식적인 정상 범위나 오류 판정 기준이 아니므로 원본을 자동 수정하거나 삭제하지 않았습니다.

사용자 자원 값이 NONE인 이벤트는 399,090개입니다. 기록이 없다는 이유로 실제 사용자가 없었다고 해석하지 않습니다. 같은 시각의 이벤트도 파일 순서만으로 인과관계를 결정하지 않습니다.

## 첫 질문과 후속 관문

첫 후보 질문은 “이 발주 항목의 첫 Clear Invoice 이전에 Record Goods Receipt가 기록되어 있으며 어느 이벤트가 근거인가?”입니다. 관측된 로그에 대한 질문으로 제한합니다. 앞선 입고 기록이 있다는 사실만으로 취소되지 않은 잔량이나 실제 지급 적합성을 보장하지 않습니다.

첫 실험 전에 Clear Invoice가 없는 경우, 같은 시각의 처리, 취소·변경의 포함 범위와 근거 위치 표기를 고정해야 합니다. 같은 발주의 여러 항목이 개발·평가에 나뉘지 않도록 발주 문서 단위로 분리합니다. 전체 집계를 살피고 예시를 읽었으므로 이번 검사는 탐색 단계이며 미열람 평가 결과가 아닙니다.

자연어 원본 송장이나 PDF 묶음은 이 자료에 없습니다. [원천·규칙 구축 설계](../experiments/source-to-rule-guide.md)의 자연어 변환은 공개 업무 설명을 별도로 고정해 평가해야 합니다. 그래프 경로 재사용을 보여 줄 수는 있지만 깊은 OWL 추론의 필요성이나 그래프의 성능 우위는 별도 비교가 필요합니다.
