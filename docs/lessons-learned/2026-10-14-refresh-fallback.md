# 2026-10-14 — 공유 조회 장애와 기존 답의 보존

## Context

공급 국가·제한 점검·추천 세 업무가 한 번의 원천 조회를 공유하도록 구현했다. 비용이 바뀐 추천만 추가조회가 필요해도 세 답을 함께 다시 계산하는 구조였다.

## Incident

최초 구현은 요청한 조회가 실패하면 세 답을 모두 보류했다. 올바른 카탈로그 조건에서 선택 조회의 정답 제공이 보류 유지보다 284개 줄었다. 기존 검사에서 이미 통과했던 국가·제한 답까지 추천 조회 장애의 영향을 받았다.

## Lesson

묶음 단위 조회와 답의 제공 여부는 구분한다. 조회 전에 검사를 통과했던 답만 복원 후보로 삼고 기존 답과 새 답을 합친 뒤에도 업무 간 모순을 다시 검사한다. 장애가 났다는 이유로 원래 검사를 통과하지 못한 답을 허용하지 않는다.
