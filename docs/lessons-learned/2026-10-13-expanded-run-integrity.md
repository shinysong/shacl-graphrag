# 2026-10-13 — 확대 실행의 표본 제한과 병렬 결과 보존

## Context

개발용 모델 점검을 확대한 뒤 별도 평가 집합으로 진행하려 했다.

## Incident

작은 점검의 첫 실행에서 `--limit-subjects 2`를 빠뜨려 개발 72개 사례가 예정 목록에 들어갔다. 이를 발견하고 SIGINT로 중단했다. 호출 7회와 예약액 $0.0097296을 보존했으며 응답을 받지 못한 호출의 실제 청구액은 확정하지 않았다. 원시 기록은 중단 직전 상태를 유지하고 별도 종료 메모를 남겼다. 수정한 명령으로 새로운 실행을 만들었다.

병렬 실행의 독립 검토에서는 작업 디렉터리 생성이나 클라이언트 종료 예외가 다른 완료 결과의 수집을 끊을 수 있다는 문제가 발견됐다. 작업 전체를 보호하고 예외 뒤 새 작업을 중단하되 이미 시작한 작업은 끝까지 수집하도록 수정했다. Jev 검토에서는 비정상 비용 응답 구조가 중단 조건을 우회할 수 있어 응답과 usage 객체의 타입 검사 및 회귀 테스트를 추가했다. 실제 비용 누락이 발생했다는 뜻은 아니다.

## Lesson

소규모 실행의 표본 제한은 명령과 예정 결과 행 수로 함께 확인한다. 중단된 호출은 성공한 응답과 구분하고 예약액을 유지한다. 병렬 작업 하나의 예외가 다른 작업의 기록을 버리게 해서는 안 된다.
