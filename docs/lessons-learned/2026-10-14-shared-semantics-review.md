# 2026-10-14 — 공통 규칙 실험의 비교 범위와 검토 분량

## Context

업무별 규칙 사본과 공통 규칙을 비교하면서 JSON·RDF 추출본의 동기화 오류도 함께 확인하려 했다.

## Incident

첫 검토 두 건은 진행 가능으로 제출됐지만 소스 발췌와 검토 결과를 합친 종합 검토 요청이 28,000바이트 문맥 한도를 넘었다. 실험과 테스트는 아직 시작하지 않았다. 소스는 유지하고 검토 문서의 발췌 범위를 줄인 새 작업에서 독립 검토를 다시 받았다. 새 검토에서는 시드 17과 29가 3으로 나눈 나머지가 같아 상태별 지연 대상 업무가 동일하다는 점도 확인했다.

## Lesson

검토 문서는 최초 요청 크기뿐 아니라 후속 검토와 종합 결과를 합친 크기도 고려한다. 생략한 구현은 검토자가 확인했다고 표시하지 않는다. 난수 시드가 다르더라도 관심 사례와 오류 대상이 같으면 독립적인 업무 표본이 늘어난 것으로 해석하지 않는다.

공통 규칙 하나의 지연이 여러 업무에 영향을 주는 구조와 업무별 사본 하나의 지연을 비교할 때는 주입한 오류의 범위를 함께 적는다. 합계가 작다는 이유만으로 더 안전한 구조라고 결론 내릴 수 없다.
