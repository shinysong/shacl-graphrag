# 응답 미수신 호출의 비용 보존과 제한적 재개

## 발생 상황

`hybrid-complexity-1`의 첫 합성 실행은 217번째 호출에서 응답을 받지 못해 중단됐다. 앞선 216회 응답은 정상적으로 보존됐고 72문항이 완료됐다. 다음 문항의 첫 `hybrid_pre` 요청은 요청 파일만 남아 있으며 응답 본문과 생성 ID가 없다.

## 원인과 확인 범위

당시 실행기는 비용을 확인하지 못하면 중단했지만 원래 예외의 종류는 저장하지 않았다. 따라서 이 기록만으로 연결 실패와 읽기 시간 초과 등을 구분할 수 없다. 비용을 확인하지 못했다는 사실을 청구되지 않았다는 뜻으로 해석해서도 안 된다.

## 수정과 재개 조건

후속 호출부터 예외 종류와 경과 시간을 별도 파일에 남긴다. 예외 메시지나 인증 정보는 기록하지 않는다. 실패한 호출의 예약액과 `missing_cost=1`은 원래 장부에 보존한다.

완료한 72문항을 다시 실행하지 않고 미완료 48문항만 새 디렉터리에서 실행한다. 대상은 결과의 좋고 나쁨이 아닌 실행 상태로 선택했다. 중단된 문항의 호출을 한 번 명시적으로 다시 시도하므로 이번 전체 상한은 840회에서 841회가 된다. 기존 잔여 842회와 캠페인 전체 3,200회 한도는 그대로 유지한다.

재개 전에는 새 독립 검토와 전체 소프트웨어 테스트를 수행했다. 이후에 비용 미확인 호출이 다시 발생하면 다음 실행까지 모두 중단한다. 원래 실패 행, 미실행 행, 재개 결과를 각각 남기며 재시도한 문항을 제외한 민감도 분석도 함께 보고한다.

## 해석상의 주의점

완료한 재개 결과를 최초 시도에서 오류 없이 끝난 실행으로 표현하지 않는다. 보고된 사용액에는 미확인 호출의 실제 청구액이 빠져 있음을 표시하고 모든 호출의 예약액을 별도로 공개한다. 전송 계층의 오류와 모델의 판단 오류도 구분한다.
