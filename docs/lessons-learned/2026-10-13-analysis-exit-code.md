# 2026-10-13 — 분석 기록의 종료 코드 표기

## Context

사용자가 당일 연구 운영 한도를 105회로 늘린 뒤 새 검토 작업을 만들었다. 독립 검토와 종합 검토를 마치고 소프트웨어 테스트 143개가 통과했다.

## Incident

마지막 분석 요약에 `unit-tests completed with exit code0`이라고 적었다. 제출 검증기는 검사 이름 뒤에 단어 경계로 구분된 종료 코드가 있는지 확인하므로 `code0`을 인정하지 않았다. 제출이 거절됐고 예약된 105번째 요청은 그대로 소비됐다. 새 요청이 필요한 재제출은 하지 않았다.

## Lesson

관측 결과는 `unit-tests: exit code 0`처럼 검사 이름과 종료 코드를 명확히 구분한다. 제출 전에 결과 JSON의 계약과 요약 표기를 확인한다. 단순 표기 오류여도 실패 기록을 고치거나 예약을 되돌리지 않는다.

## Follow-up

- [x] 거절된 제출과 기존 검토·테스트 기록 보존.
- [x] 검토·테스트 통과 조건을 확인한 뒤 별도 오프라인 실험 실행.
- [x] 기본 한도 100회 복원과 유료 API 미호출 확인.
- [ ] 허용된 후속 요청에서 분석 기록 재제출. 연구 운영 작업은 아직 완료 상태가 아니다.
