# 2026-11-04 — 복합 답변의 출력 한도와 실패 분모

## Context

6개 모델에 9개 질문 유형을 주고 실제 초안·자체 검토·SHACL 보고서 검토를 비교했다. 공통 출력 상한은 추론 토큰을 포함해 2,048토큰이었다.

## Incident

154회 호출 중 길이 제한 실패가 8건 발생했다. 근거 부족과 추가 검토 자료를 함께 묻는 Q8에 6건, 작성된 오류를 검토하는 Q9에 2건이 집중됐다. JSON 필수 키 손상도 1건 있었다. 초안 실패에 의존한 검토 8건은 실행하지 않았고 재시도하지 않았다.

최종 감사 코드의 첫 검토에서는 실행 종료 확인과 요청 전체의 비교가 부족했다. 예약 상태가 없다는 사실만으로 종료를 판정하면 호출 사이의 순간을 완료로 잘못 볼 수 있다. 동일 실행 잠금을 잡고 출력 한도·제공업체·가격 설정과 시각별 예산 승인을 재현하도록 수정한 뒤 새 독립 검토를 거쳤다.

## Lesson

입력의 크기 점검만으로 복합 답변의 완성을 보장할 수 없다. 추론량, 답변 본문과 검증용 선언의 길이를 함께 고려해야 한다. 완료된 답변만 비교하면 실패가 많은 질문이 빠지므로 전체 예정 결과와 같은 초안의 완료 묶음을 별도로 보고한다.
