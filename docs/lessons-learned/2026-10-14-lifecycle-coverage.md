# 2026-10-14 — 전체 결과 검증의 누락 방지

## Context

JSON과 Neo4j 변경 실험을 준비하며 저장된 스냅샷을 RDFLib SPARQL로 대조하는 검증기를 추가했다.

## Incident

첫 독립 검토에서 검증기가 스냅샷 일부를 받지 않아도 불일치가 없으면 완료로 표시할 수 있다는 문제가 나왔다. 실제 실험은 시작하지 않은 상태였다. 수정 뒤 새 검토 작업을 만들었다. 종합 검토 제출에서 허용되지 않는 결정값 `approve`를 사용해 한 번 거절됐고 기존 기록을 보존한 뒤 `ready`로 재제출했다.

## Lesson

불일치가 없다는 사실과 예정된 결과를 모두 확인했다는 사실을 별도로 검증한다. 선언된 규모·반복·변경 지점·질문·비교군의 조합으로 전체 결과 목록을 다시 만들고 중복과 누락 및 ID 대응을 확인한다. 연구 운영 제출값은 자유 표현 대신 정해진 계약을 따른다.

## Follow-up

- [x] 전체 조합과 최종 비교 집합을 확인하는 검증 추가.
- [x] 누락·중복·ID 오류·정상 전체 조합 테스트 추가.
- [x] 새 독립 검토 두 건과 소프트웨어 테스트 155개 통과.

## SPARQL 대조의 후속 수정

첫 대조 질의는 큰 중간 조합을 탐색해 오래 걸렸다. 완전한 스냅샷 16개와 다음 스냅샷의 질의 2개까지, 총 322개 질의·966행을 대조한 상태에서 의도적으로 중단했다. `KeyboardInterrupt` 실패 상태와 원래 질의를 보존했다. `BIND`로 제품에서 공급자·지역·국가로 따라가는 질의 구간을 나눴고, 조건과 반환 경로는 유지했다. 새 검토와 테스트 이후 같은 스냅샷을 새 출력으로 대조한다. 이 변경은 검증기에만 적용하며 완료된 DB 실험을 다시 실행하지 않는다.

새 검증은 48개 스냅샷·960개 질의·2,880행 전체에서 불일치 없이 완료됐다.
