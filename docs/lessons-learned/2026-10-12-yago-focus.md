# 2026-10-12 — YAGO 중첩 제약과 검증 범위

## Context

YAGO 4.6의 원본 SHACL을 유지하면서 질의 인물과 출생지 근거를 pySHACL로 검사했다.

## Incident

첫 사전 점검에서 `focus_nodes`로 인물·장소 URI를 지정하자 `sh:or` 아래의 날짜 리터럴 검사가 빠졌다. 잘못된 `xsd:string` 출생일이 통과했다. 필터를 제거한 두 번째 실행에서는 taxonomy의 클래스 노드까지 검사하면서 생략된 클래스 라벨을 위반으로 보고했다. 두 실행은 `functional_mismatch`로 보존했고 LLM은 호출하지 않았다.

## Lesson

전체 검사를 수행한 뒤 질의 인물·출생지 노드의 최상위 결과를 추린다. 이는 질의 근거 범위의 판정이며 전체 YAGO의 적합성 판정이 아니다. 중첩된 자료형 제약을 위반하는 음성 사례를 회귀 테스트에 포함한다.
