기존 72회 중 원래 실패한 1회를 보존하고 71개 답변의 명시적인 인용 위치를 재생했습니다. 아래는 주장·인용 쌍 100개의 값 비교입니다.

경고가 곧 오답은 아닙니다. 셀 주소를 설명한 주장도 셀 내용과 비교하면 경고가 납니다. 질문 적용성·본문의 주장 누락·단위·외부 사실·수정 효과는 이 화면에서 평가하지 않습니다.

Python과 pySHACL의 항목별 결과가 같아 한 번만 표시합니다. 두 엔진은 같은 위치 해석 코드를 공유합니다. 원본 출처의 진위나 독립적인 의미 해석을 검증한 결과가 아닙니다.
