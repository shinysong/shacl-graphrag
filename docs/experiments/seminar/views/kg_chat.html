① 문서와 요구 조건을 프롬프트로 전달

입력

문서: “볼트 P1은 조립품 A1에 장착된다.”

업무 조건: “P1의 제조사를 IRI로 하나 이상 기록해야 한다.”

프롬프트 예시

문서의 사실을 data.ttl로, 업무 조건을 SHACL 문법의 shapes.ttl로 작성해 줘.

타입은 Bolt, 관계는 installedIn과 manufacturer를 사용해. 제조사 값은 문서에 없으니 data에는 추가하지 마.

② RDF와 Shape 초안 · 기대 출력 예시
# data.ttl
ex:P1 a ex:Bolt ;
  ex:installedIn ex:A1 .

# shapes.ttl
ex:ManufacturerShape a sh:NodeShape ;
  sh:targetNode ex:P1 ;
  sh:property [
    sh:path ex:manufacturer ;
    sh:minCount 1 ;
    sh:nodeKind sh:IRI
  ] .

③ 파일 저장 → RDF 파싱 → pySHACL 실행
