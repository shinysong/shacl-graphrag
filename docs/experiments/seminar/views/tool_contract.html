replacement_candidates요구 역량을 갖춘 설비 후보제품별 유효 자격 · 실제 일정 여유
qualification_records설비의 자격 코드·제품·유효기간작업장 부하 · 납기 준수 · 현장 승인
impacted_orders특정 설비에 배정된 주문 목록대체 설비의 적격 여부

온톨로지 · SHACL · 검사기의 역할 분담

온톨로지 (개념 정렬): 도구가 반환하는 Machine, Capability, Qualification의 관계와 상태 정의를 통일
SHACL (입력 근거 검사): 최종 판단 전에 선택된 후보에 대해 제품·역량·기준일 자격 근거가 실제로 조회됐는지 확인
명시적 한계: LLM이 질문을 잘못 해석했거나 엉뚱한 도구를 선택한 문제까지 검사기가 자동으로 해결하지는 못함
