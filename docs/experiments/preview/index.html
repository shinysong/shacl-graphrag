비교 범위와 생략한 조건

가상 인물 민서와 가상 도시 해솔시를 사용하는 구조 설명입니다. 네 카드는 판단 방식의 대표 구조이며 연구계획의 모든 비교군을 뜻하지 않습니다. 코드와 SHACL에는 같은 질문별 기준을 적용합니다. SHACL 카드의 ‘질문별 정책’은 누락과 위반을 구분하는 별도 해석 계층입니다. SHACL 자체가 3값 판정을 반환한다는 뜻은 아닙니다.

판단 모델 카드에서는 일반 LLM과 Jev를 각각 같은 위치에 넣어 비교할 예정입니다. 이 구조는 두 모델이 동등하거나 항상 같은 판단을 한다고 전제하지 않습니다. 재생에는 명시한 기준대로 판단하는 가상 경로 하나를 사용합니다. 실제 모델이 오류를 놓치거나 과도하게 보류하는지는 실험으로 확인해야 합니다. Jev 1.13은 별도 개발 실행에서 실제 호출했습니다. 아래 실행 기록에서 결과와 적용 범위를 확인할 수 있습니다.

추가조회는 같은 원천에서 최대 1회입니다. 규칙 위반은 바로 보류하고 확인 불가일 때만 추가조회합니다. 무검증은 타입 검사 없이 후보 하나를 추출하며 후보가 없거나 여러 개면 보류합니다. 이 예시는 후보 0개 또는 1개를 사용합니다. 출력 상자는 결정적 추출기 기준이며 실제 연구에서는 동일한 답변 LLM을 추가해 생성 오류를 따로 비교합니다.

무조건 1회 재조회, SHACL+LLM·Jev 결합, 규칙 변경 과제는 전체 연구계획에 포함되지만 이 네 카드에서는 생략했습니다. 결합 조건에서는 규칙 위반을 먼저 차단하고 규칙과 모델이 모두 충족해야 답변에 사용합니다. 사실 정확성을 평가하는 정답은 검색·검사·복구 입력으로 전달하지 않습니다. 원본 YAGO shapes는 보존하며 별도 질문별 계약을 사용합니다.
