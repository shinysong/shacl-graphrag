# 2026-10-14 — 업무·버전·의미 검사의 효과와 과잉 보류

실행 ID는 `20261014T101134Z-semantic-guards`, 프로토콜은 `semantic-guards-1`이다. [이전 실행](20261014-shared-semantics.md)의 답 12,288행에 검사 여섯 조건과 카탈로그 세 조건을 적용했다. 예정한 221,184개 판정을 모두 기록했고 실행 오류와 누락은 없었다. 새로운 질문 221,184개를 생성한 결과는 아니다.

## 올바른 필드 설명에서의 검사 비교

각 행은 같은 기존 답 12,288개를 검사한 결과다. 기존 출력에는 현재 원천·업무 계약과 다른 답 1,416개와 맞는 답 10,872개가 있었다. 맞는 답 가운데 7,680개는 결정 가능한 답, 3,192개는 계약에 맞는 확인 불가였다.

| --- | ---: | ---: | ---: | ---: |
| 없음 | 1,416 | 0 | 10,872 | 0 |

불필요한 보류는 원래 맞고 결정 가능했던 답을 보류한 수다. 출력 일치 기준이라 잘못된 매핑으로 우연히 같은 답을 낸 경우도 포함하며, 업무상 부적절한 보류인지까지 판정한 지표는 아니다. 원래 확인 불가였던 답의 추가 보류는 이 열에서 제외했다. 모두 적용은 이를 1,280개, 선택 적용은 1,104개 추가 보류했다. 이 수까지 포함하면 맞는 답의 전체 보류는 각각 3,760개와 3,148개다.

선택 적용은 모두 적용과 같은 1,416개의 오답을 보류하면서 불필요한 보류를 436개 줄였다. 이 집합에서 17.6% 감소한 값이다. 맞는 출력의 유지는 612개 늘었고 그중 176개는 확인 불가 출력이었다. 오답은 정답으로 복구하지 않고 보류했으며 선택 적용도 결정 가능한 정답 2,044개를 보류했다.

## 카탈로그 신뢰에 따른 실패

| 카탈로그 | 선택 적용의 오답 통과 | 맞는 답 유지 | 불필요한 보류 |
| --- | ---: | ---: | ---: |
| 올바른 설명 | 0 | 7,724 | 2,044 |
| 설명 없음 | 0 | 0 | 7,680 |
| 잘못된 설명 | 1,040 | 9,756 | 780 |

설명이 없을 때 오답 통과가 0인 것은 모든 답을 막았기 때문이다. 이것만 보고 안전성이 높다고 판단하면 답을 전혀 제공하지 못하는 정책을 좋은 결과로 오해하게 된다.

세금 관련 국가 필드를 공급 국가로 잘못 설명하면 의미 검사가 그 설명을 받아들였다. 모두 적용과 선택 적용 모두 1,040개의 오답을 통과시켰다. 버전과 업무 간 결과가 맞아도 카탈로그까지 함께 틀린 의미 오류는 이번 검사로 발견하지 못했다. 카탈로그가 실제 원천 문서와 일치하는지 확인하는 과정은 측정하지 않았다.

## 질문별 실제 판정

아래는 제품 24개·시드 17의 RDF 하이브리드 출력이다. 이미 저장한 SPARQL 결과를 검사했으며 이번 실행에서 SPARQL을 다시 호출하지 않았다. 평가 기준은 사후 대조에만 사용했다.

### 비용 변경과 추천 보류

제품 p4의 공급자는 s0와 s4다. s0의 비용이 30에서 5로 바뀌었지만 추출본은 이전 비용을 유지했다.

| 질문 | 기존 답 | 현재 계약의 답 | 전체 검사 | 선택 검사 |
| --- | --- | --- | --- | --- |
| 공급 국가는? | C0·C1 | C0·C1 | 보류 | 유지 |
| 제한 국가가 있는가? | 없음 | 없음 | 보류 | 유지 |
| 비용이 가장 낮은 허용 공급자는? | s4 | s0 | 보류 | 보류 |

전체 버전 검사는 원천 변경을 보고 세 답을 모두 보류했다. 선택 검사는 국가·제한 질문에서 비용을 의존성에 넣지 않으므로 앞의 두 답을 유지했다. 추천은 비용 변경이 영향을 주기 때문에 보류했다. s0로 고쳐 답한 것은 아니다.

### 공급 국가와 세금 관련 국가의 혼동

제품 p4에서 C1을 제한하는 상태에 잘못된 매핑을 주입했다. 기존 출력은 공급 국가 C0, 제한 없음, 공급자 s4 추천이었다. 현재 계약에서는 국가 C0·C1, 제한 있음, s0 추천이 맞는다.

업무 대조와 버전 검사는 통과했다. 올바른 카탈로그를 사용한 의미 검사는 `conflict:tax_country`를 남겨 세 답을 보류했다. 카탈로그도 같은 필드를 공급 국가로 잘못 설명하면 세 답 모두 통과했다. 제공된 의미 설명과 정합성이 맞는지 검사한 결과다. 진실을 스스로 찾아내는 판정은 수행하지 않았다.

### 공유 설정의 지연과 함께 맞는 답

예비 공급자 허용 뒤 제품 p0의 공통 설정이 지연되면 국가 C0, 제한 없음, s0 추천이 나온다. 현재 계약의 답은 C0·C1, 제한 없음, s1 추천이다. 선택 적용은 허용 역할 설정의 변경을 보고 세 답을 모두 보류했다. 이때 제한 없음은 원래도 맞는 답이지만 함께 막혔다. 질문별 필드 의존성을 나눠도 실제 출력 변화까지 판별하는 최소 검사 범위가 되지는 않았다.

## 검증과 실행 자원

독립 방법론·구현 검토 뒤 등록 단위 검사 172개가 64.443초에 통과했다. 실행은 24.77초, 클라이언트 최대 RSS는 96,408 KiB였다. 유료 모델 API 호출은 0회이며 DB 서버를 실행하지 않았다. 이 시간은 기존 출력을 파일 기반으로 재검사하는 데 걸린 시간이다. 서비스 질의 지연이나 저장 엔진 성능은 측정하지 않았다.

별도 분석기가 221,184개 행의 ID·누락·점수·검사 조합과 기존 12,288개 평가 기준을 대조했다. 입력 파일 1,511개의 해시를 확인하고 실행 소스도 보존했다. 저장된 운영 패킷 1,536개로 검사 상태 884,736개를 추가 재계산했다. 원천에서 의존성 지문을 만드는 과정 전체는 별도 구현으로 검증하지 않았다. 규모·시드는 기존 고정 관심 사례를 반복하므로 통계적 독립 표본으로 다루지 않는다.
