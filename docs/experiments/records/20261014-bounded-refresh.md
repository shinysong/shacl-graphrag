# 2026-10-14 — 제한된 추가조회와 장애 시 답 보존

첫 실행 `20261014T144112Z-bounded-refresh`에서 331,776행과 110,592개 업무 묶음을 처리했다. 기존 12,288개 답을 카탈로그·서비스·정책 조건으로 반복한 결과다. 새 질문 331,776개를 평가한 것은 아니다. [프로토콜](../bounded-refresh-study.md)에 실행 범위와 재현 경로를 기록했다.

## 현재 원천을 반환한 조건

올바른 필드 설명이 주어진 조건에서 각 정책은 같은 답 12,288개를 처리했다. 원천 조회 한 번은 세 업무가 공유하는 JSON 스냅샷 읽기다.

| 정책 | 통과한 정답 | 오답에서 복구해 통과 | 조회 횟수 |
| --- | ---: | ---: | ---: |
| 보류 유지 | 7,724 | 0 | 0 |
| 선택 조회 | 9,216 | 376 | 592 |
| 매번 조회 | 9,216 | 376 | 3,072 |

선택 조회는 매번 조회보다 2,480회 적게 읽고 같은 수의 정답을 제공했다. 이 집합에서 조회 횟수는 80.7% 적었다. 읽은 파일 크기는 각각 10,998,584바이트와 57,067,008바이트다. 실제 네트워크 지연이나 API 요금 절감을 측정한 값은 아니다.

오답 통과는 세 정책 모두 0이었다. 선택 조회로 제공한 정답은 보류 유지보다 1,492개 늘었다. 그중 376개는 원래 틀린 답을 원천으로 다시 계산해 고친 경우이고 나머지 1,116개는 원래 출력이 맞았지만 검사를 통과하지 못했던 경우다.

의미 설명이 잘못된 조건에서는 선택 조회와 매번 조회 모두 오답 1,040개를 그대로 통과시켰다. 최신 원천에서 같은 잘못된 필드를 읽어도 매핑 오류는 해결되지 않았다. 설명이 없는 조건에서는 의미 검사가 모든 답을 보류해 조회도 실행하지 않았다.

## 조회 서비스 실패와 기존 답의 손실

추가조회가 실패하면 최초 구현은 해당 묶음의 세 답을 모두 보류했다. 올바른 설명 조건에서 선택 조회의 정답 제공은 7,440개로, 보류 유지의 7,724개보다 284개 적었다. 매번 조회는 3,072개 묶음의 요청이 모두 실패해 정답 제공이 0개가 됐다.

제품 p4에서 비용만 달라진 경우가 이 문제를 드러냈다. 국가 목록과 제한 여부는 기존 근거로 답해도 됐지만 추천에 필요한 추가조회가 실패하면서 함께 막혔다. 실패한 조회가 다른 답까지 없애지 않도록 보완했다.

## 기존 답 보존 보완 결과

`20261014T144914Z-refresh-fallback`은 첫 실행의 선택 조회 응답을 재사용해 110,592행을 평가했다. 조회 전 검사를 통과한 답만 복원 후보로 삼고 새 답과 섞은 뒤에도 세 검사를 다시 수행했다.

| 올바른 설명 조건 | 기존 선택 조회의 정답 제공 | 보완 정책의 정답 제공 |
| --- | ---: | ---: |
| 현재 원천 응답 | 9,216 | 9,216 |
| 서비스 실패 | 7,440 | 7,724 |
| 초기 원천 응답 | 8,704 | 8,704 |

장애 때 잃었던 정답 284개를 유지했고 보완으로 새로 통과한 오답은 전체 파생 평가에서 0개였다. 284개 가운데 212개는 결정 가능한 답, 72개는 원래 확인 불가가 맞았던 답이다. 잘못된 설명 조건에서도 기존 정답 284개를 유지했지만 이미 통과하던 오답 1,040개는 그대로 남았다.

보완 평가에서는 새 원천 조회를 수행하지 않았다. 정책 비용은 기존 선택 조회의 조건별 592회를 물려받은 비교값이며, 실제 추가로 592회를 호출했다는 뜻이 아니다. 최초 결과와 보완 결과를 별도 실행 폴더에 보존했다.

## 실제 질문의 처리 흐름

제품 24개·시드 17의 p4에서 s0의 비용이 30에서 5로 바뀌고 추출본은 이전 비용을 가진 사례다. 최초 답은 RDF 조회에서 나왔지만 이번 추가조회는 공통 JSON 경로로 수행했다.

| 질문 | 기존 답 | 현재 응답 뒤 | 실패 응답 뒤 보완 정책 |
| --- | --- | --- | --- |
| 공급 국가 목록 | C0·C1 | C0·C1 제공 | 기존 C0·C1 유지 |
| 제한 국가 존재 | 없음 | 없음 제공 | 기존 없음 유지 |
| 비용이 가장 낮은 허용 공급자 | s4 | s0로 복구 | 보류 |

현재 원천에서 국가 정보가 삭제된 p3은 다시 읽어도 확인 불가다. 추가조회로 없는 값을 채우지 않았다. 반대로 현재 답이 정상인데 매번 조회가 초기 원천을 받아오면 최신 근거를 오래된 근거로 바꿀 수 있었다. 재검사가 이를 보류했지만 답을 제공할 수 있는 범위는 줄었다.

올바른 설명·초기 원천 응답 조건에서 매번 조회는 기존 정답 904개를 오답으로 바꿨고 선택 조회에서는 192개가 바뀌었다. 재검사가 이 답들을 모두 보류해 통과한 오답으로 이어지지는 않았다. 출력 자체의 악화와 잘못된 답의 제공을 구분할 필요가 있다.

초기 원천 응답 조건에서 선택 조회는 정답 8,704개, 매번 조회는 7,872개를 제공했다. 이때 복구해 통과한 오답은 각각 80개다. 역할 허용 등 설정만 바뀐 경우에는 초기 원천을 여전히 사용할 수 있기 때문이다. 초기 상태 자체도 포함하므로 이 조건의 모든 응답을 실제로 낡은 답으로 간주하지 않는다.
