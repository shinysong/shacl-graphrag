## 실제 입력과 도출 과정

### 제품의 공급 국가

사례 `g052:q08`의 실제 식별자는 `urn:ontology-study:g052:e500`, `e501`, `e502`로 끝난다. 아래 제품·업체·국가 표기는 읽기 위한 설명이며 모델이 생성한 응답이 아니다.

```text
입력: 제품(e500) ─provider→ 업체(e501) ─region→ 국가(e502)
매핑: provider → suppliedBy / region → locatedIn
공리: suppliedBy 다음 locatedIn이면 supplyCountry
도출: 제품(e500) ─supplyCountry→ 국가(e502)
```

명시 사실 조회는 `unknown`, JSON과 OWL-RL은 모두 `entailed`를 반환했다. JSON의 도출 기록에는 두 원천 사실, 두 어휘 매핑, 관계 합성 공리가 남아 있다. OWL-RL에서도 같은 결과 트리플을 실제 출력에서 확인했다. JSON의 도출 기록을 OWL-RL이 제공한 증명으로 부르지는 않는다.

매핑이 없는 대응 구성 `g048:q08`에서는 세 방법 모두 `unknown`이었다. 데이터 이름만 보고 공급 관계의 의미를 추측하지 않았다. 사람이 명시한 매핑의 정확성은 이번 평가 대상이 아니다.

### 직접 관계와 간접 관계

`g052:q03`은 여덟 링크 끝의 조직이 출발 조직의 직접 상위 조직인지 묻는다. 간접적인 조상 관계는 도출되지만 직접 관계는 도출되지 않아 세 방법 모두 `unknown`이다. 직접 관계 자체를 전이적으로 선언하지 않았기 때문이다.

### 개념 충돌과 질문의 구분

`g053:q07`의 그래프에는 상위 개념을 따라가면 서로 배타적인 두 클래스에 속하는 대상이 있다. 두 추론기는 이 충돌을 찾았지만 무관한 다른 대상의 타입을 묻는 질의는 `unknown`으로 남겼다. 충돌 표시가 있다고 모든 질문이 거짓이 되거나 임의의 답이 생성되는 방식으로 구현하지 않았다.

충돌 그래프 32개는 모두 탐지했고 정상 그래프 32개를 잘못 충돌로 표시한 경우는 없었다. 이 탐지는 그래프 전체의 배타 클래스 증거를 확인한 것이며 완전한 OWL 일관성 검사는 아니다. 모순된 그래프에서 `entailed`는 실행한 양의 규칙의 결과에 트리플이 있다는 표시로 사용한다.

## 실행 비용과 재현 기록

전체 실행은 6.31초, 관측 최대 상주 메모리는 35,512 KiB였다. API 호출은 0회이며 AWS와 Codex 비용은 별도다. 그래프당 처리 시간 중앙값은 명시 조회 0.408 ms, JSON 0.693 ms, OWL-RL 55.609 ms였다. 구현마다 추론·증명 기록·진단·직렬화 범위가 달라 순수 추론 속도 비교로 해석하지 않는다. 시간은 그래프·비교군당 한 번 측정했으며 10개 질의 행에 반복 기록된 값을 중복 합산하지 않았다.

실험 전에 소프트웨어 테스트 143개가 53.287초에 통과했다. 이 테스트와 실제 1,920행 실행은 별도 기록이다. 실행 후 원천·평가 파일 해시와 실행 코드 해시를 확인하고 192개 출력 그래프를 다시 읽어 모든 질의 판정과 대조했다. JSON 도출 기록의 말단 근거가 입력에 존재하는지도 확인했다. 사용한 버전은 rdflib 7.6.0, owlrl 7.6.2다.

연구 운영은 사용자가 승인한 당일 105회 한도를 지켰고 기본 설정은 100회로 복원했다. 독립 검토 두 건, 종합 검토와 테스트는 완료했다. 마지막 분석 기록 제출은 종료 코드 표기 `code0` 때문에 거절됐다. 당시에는 연구 운영 작업 전체를 완료 상태로 표시하지 않았다. 2026-10-14에 같은 소스와 검사 결과를 유지한 채 표기를 `unit-tests: exit code 0.`으로 수정해 재제출했고, 연구 운영 기록도 완료했다. 이날은 기본 100회 한도를 적용했다.
