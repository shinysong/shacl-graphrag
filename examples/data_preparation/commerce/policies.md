# 가상 쇼핑몰 정책 — 입력 검토용 예제

이 문서는 실제 사업자의 약관이 아닌 작성된 테스트 자료입니다. 적용일은 2026-11-17입니다.

무료배송 금액은 할인 전 상품 합계로 계산합니다. 배송 정책별 최소 금액과 배송비는 shipping_policies.csv를 따릅니다.

쿠폰은 할인 전 상품 합계가 coupons.csv의 minimum 이상일 때 적용합니다. 할인액은 discount이며, 상품 합계를 넘을 수 없습니다.

쿠폰 최소 금액 미달 시 주문·교체 옵션·할인액이 모두 일치하는 승인 기록이 있어야 해당 할인을 유지할 수 있습니다.

출고 전 주문만 변경할 수 있습니다. 교체 옵션은 같은 상품과 같은 사이즈여야 하며, 해당 옵션에 대한 고객 동의가 필요합니다.

가용 재고가 주문 수량 이상인지 확인합니다. 빈 재고 셀은 정보 부족이며 0으로 바꾸지 않습니다.

도착일 확약에는 고객 요청일 이내의 확정된 도착 기록이 필요합니다. 도착일이 비어 있으면 배송 가능을 단정하지 않습니다.

부분 출고 허용 여부는 shipping_policies.csv의 split_allowed를 따릅니다.
