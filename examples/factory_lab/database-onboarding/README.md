# 쇼핑몰 SQLite 연결 예시

`shop.sql`은 이 프로젝트에서 작성한 가상 자료입니다. 자료와 SQL 정의는 CC0-1.0으로 제공합니다. 실제 고객 정보나 운영 정책은 포함하지 않습니다.

- products: 상품 6행, 상품번호·이름·기록된 가용 수량
- orders: 주문 2행, 주문번호·상태·요청일
- order_items: 주문항목 3행, 주문번호·상품번호 참조·수량

새 저장소 → DB 연결하기 → 예시 SQLite DB 연결을 누르면 실제 SQLite 파일을 만들고 기존 등록 DB 경로로 전체 스냅샷을 저장합니다. 같은 서버에서 다시 연결하면 원본 스냅샷을 재사용하되 새 저장소의 검토는 모두 대기 상태로 시작합니다.

연결은 스키마와 제한된 표본을 읽는 작업입니다. LLM을 호출하거나 업무 의미를 자동 확정하지 않습니다. DB 실행 기능이 설정된 서버에서 사용할 수 있으며 로컬 서버는 `--workspace-database-registry`를 지정해야 합니다.

상품 3개 열부터 검토할 수 있습니다. 제공된 상품 조회 정의는 고정 예제 템플릿이며 모델 생성물이 아닙니다. 필드와 조회 정의를 각각 승인한 뒤 기존 조회 또는 채팅에 사용합니다. 나머지 주문 관련 7개 열은 승인하지 않아도 됩니다. 재고 기록을 읽는 것과 실제 재고 예약·주문 변경은 다릅니다.

LLM 의미 제안을 시험하려면 NVIDIA auto-ontology가 연결된 서버에서 **LLM으로 의미 초안 제안받기**를 누릅니다. 실행 창에서 대상 저장소를 확인하고 유료 실행을 별도로 시작합니다. 결과는 승인 대기로 보관하며 개념·필드·관계 제안과 출처를 검토할 수 있습니다. 이 기능이 필드 승인이나 실행할 조회 정의를 자동 승인하지는 않습니다.
