내 데이터 넣기

예제 shop.json을 복사하고 주문·상품·재고·정책·동의·승인 기록을 채우세요. 처리안은 cases에 따로 작성합니다.

uv run --locked python -m apps.factory_lab.commerce my-shop.json
uv run --locked python -m apps.factory_lab.public_server --commerce-data my-shop.json

필수 필드와 한계: docs/setup/commerce-data.md. CSV·정책 문서는 데이터 준비 화면에서 검토 후 변환합니다. 임의 자연어 정책의 자동 번역은 지원하지 않습니다. 개인정보·결제정보는 넣지 마세요.
