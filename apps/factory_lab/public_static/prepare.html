내 자료로 데이터 준비

자료 추가 → 초안 검토 → 승인 번들 저장 → 로컬 조회·검증

1. 자료 추가

CSV 여러 개와 TXT·Markdown 정책 문서를 선택하세요. 파일당 1 MB, 전체 4 MB, 최대 24개입니다. CSV는 최대 200행·64열, 문서는 파일당 256문단입니다. 관계 후보는 256개·1 MB, 전체 검토 항목은 1,024개까지 받으며 초과하면 오류를 표시합니다. 자료는 로컬 서버에서 처리하며 외부 모델에 보내지 않습니다.

이커머스 주문 변경과 제조 자격 검토를 지원합니다. 파일 이름과 열 이름의 정확한 일치, 정책 키워드로 후보를 제안합니다. 자유로운 자연어 해석이나 LLM 생성이 아닙니다.

서버 재시작 시 검토 중인 세션은 사라집니다. 이 버전은 완료된 승인 번들을 파일로 저장합니다.

열려 있는 초안

2. 초안 검토

관계 후보는 확정된 조인이 아닙니다. 현재 변환기는 컬렉션마다 한 CSV를 사용하고 기존 참조 필드를 검사합니다. 후보 관계를 승인해도 임의 조인을 생성하지 않습니다.

원본·열 분석·고정 OWL 공리




정책 해석에는 적용 대상·예외·시점을 적으세요. 실행 계약과 맞지 않는 정책은 ‘정보 부족’으로 남기세요. ‘문맥만 보존’은 규칙을 실행하지 않습니다. 제외한 항목도 기록에 남습니다.




3. 저장과 실행
미확정 항목이나 필수 매핑·정책이 있으면 구체적인 오류를 표시합니다. 실행은 임시 데이터로 실제 RDFLib 조회·pySHACL·Python 검사·OWL-RL 분류를 수행합니다. 답변은 템플릿이며 주문을 바꾸지 않습니다.
