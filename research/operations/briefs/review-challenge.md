# Proposed QA study excerpt

The proposal uses the previously inspected four-person YAGO cohort to estimate
representative generalization. It injects valid-class but factually wrong place
values. Its repair loop reads evaluator-held reference answers to replace bad
values, then reports the repaired answers as evidence that SHACL detects factual
errors. Abstentions and unsuccessful requests are removed from the reported
accuracy denominator. All experimental conditions reuse the same disclosed
subjects and no external verification source is queried.

The task is a review of this proposal only. Do not execute experiments, read any
actual evaluation answers or install services. No raw dataset values are supplied.
