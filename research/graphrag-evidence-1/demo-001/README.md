# Saved-evidence HTML demo

Open index.html locally. The HTML embeds snapshot data and Pretendard font bytes;
no server or network is needed for the interactive content. Four illustrative
posthoc cases and four retrieval conditions can be selected. Replay redraws saved
results only. D always shows the selected case's C-based report, independently of
the retrieval selector. Full24score rows, source provenance and actual dictionary
header/cell labels remain visible. The explanation reuses the prior humanized
Korean copy. No inference, answer generation or live retrieval occurs.

The combined graphrag-evidence-demo.zip includes demo-001, seminar-001 and the
notebook ZIP, preserving relative notebook links. OFL.txt preserves the local
Pretendard font license; original license bytes and manifest hashes were checked.
Source authors, DOI and CC-BY-4.0 attribution appear in the demo and snapshot.

Browser verification used cached Playwright Chromium at1280px and390px widths.
All32case-arm combinations and24table rows per viewport matched saved data.
Replay preserved the payload; Idc(A) and450 appeared from actual saved header/cell
values. No page errors, HTTP(S)requests or document overflow. Desktop/mobile
screenshots were visually inspected. The large diagram deliberately scrolls
horizontally on mobile, with an instruction; its content is not removed.
